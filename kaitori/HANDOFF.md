## このプロジェクトは何か
屋号 RAINBOW（めぐり自転車 / 個人事業主）の**出張買取現場向けタブレット記入システム**。
古物営業法の帳簿要件と電子帳簿保存法（電子取引データ）の保存要件を「仕組み」で満たすことが目的。
古物商許可番号：第511090015059号（石川県公安委員会）。譲受人：高多優典（連絡先はPDF非表示）。

- 公開想定URL：`meguri-cycle.com/kaitori/`（既存サイト `wilier300227-oss/meguri-cycle` のサブディレクトリ）
- 対象端末：Redmi Pad SE（Android / Chrome）＋ ディスク型タッチペン
- プリンター：EPSON EW-052A（Wi-Fi Direct 対応 / Bluetooth 非対応）

### 実装済みの要点
- 法定5項目（取引年月日・品目/数量・特徴・相手方[氏名/住所/職業/生年月日=年齢]・本人確認方法）を必須化。未充足だと**確定ボタン不活性＋不足項目を一覧表示**。
- 生年月日→**年齢自動算出**。18歳未満で**保護者欄＋保護者署名を自動表示**。
- 本人確認区分プルダウン。**運転免許証選択時のみ**「公安委員会名・番号」欄を表示、他区分は非表示＋値クリア（PDF・後の台帳にも出さない）。
- 取引番号 自動採番 `RB-YYYYMMDD-NNN`（localStorage で日付別連番。確定時に確定）。
- 古物商許可番号を固定表示（編集不可）。
- `signature_pad` で譲渡人（＋未成年時は保護者）の手書き署名。HiDPI対応リサイズ。
- 「確定」で確定時刻（ISO8601）記録＋フォーム全体を readonly/disabled ロック、署名パッド無効化。
- PDFは **jsPDF標準フォントが日本語非対応のため、A4 HTMLテンプレートを `html2canvas` で画像化→jsPDF に配置**する方式。日本語・署名画像をそのまま埋め込み。
  - `8月6日 ○○様 買取.pdf`（譲渡証明書 兼 代金受領書・委任状 / A4・1枚。名前は取引区分に連動＝引取なら「引取」）
  - `8月6日 ○○様 保護者同意書.pdf`（**別ファイル** / A4・1枚 / 未成年時のみ）
  - 同じ内容を **PNG画像** でも保存可（LINE公式アカウントのチャットから送るため）
- CDN読込（signature_pad 4.1.7 / jsPDF 2.5.1 / html2canvas 1.4.1）。※オフライン化はフェーズ3。

### 実機確認・修正の記録（2026-08-06）
Redmi Pad SE 実機（指操作）＋ ヘッドレスChromeによる自動検証62項目で確認。**全項目PASS / JSエラー0**。
検証スクリプトはリポジトリ管理外（作業PCのスクラッチに `verify-phase1.mjs`）。

**自動検証で見つけて直した不具合**
- 署名は input/change を発火しないため、**最後に署名すると確定ボタンが不活性のまま**だった → `endStroke` で再検証。
- A4テンプレの実高さがA4を超え、**PDFの文字が縦に潰れていた** → 縦横比を保った縮小に変更＋テンプレの余白を圧縮。
- 買取金額がラベルに `*` があるのに未検証だった → 必須に追加（引取＝0円は `0` を入力）。
- favicon の404 → `../logo/favicon.png` を参照。

**実機フィードバックによるUI変更**
- 署名欄 180px → **260px**。キャンバス解像度の算出を実寸基準に直し、ペン先と線のズレも解消。
- 職業をプルダウン化（会社員（正社員）／契約社員・派遣社員／パート・アルバイト／自営業／会社役員／公務員／学生／主婦・主夫／年金受給者／無職／その他）。
- 生年月日を **年→月→日の3プルダウン**に変更（端末の日付ピッカーは指で年に到達しづらいため）。年は当年から100年分、日リストは年月に応じて絞る。値は hidden の `#pBirth` に `YYYY-MM-DD` で同期するので既存ロジックは不変。
- 郵便番号 → 住所の自動入力（zipcloud API）。**オンライン時のみ**。住所欄は常に手入力可。**フェーズ3のオフライン化では住所データのローカル同梱に差し替えること。**
- 公安委員会を石川／富山／福井＋「その他」のプルダウンに。既定は石川。「その他」は県外免許を記録するために残してある（消すと他県免許で本人確認方法が記録できなくなる）。
- 免許証番号は数字12桁のみ入力（「第」「号」は不要）。PDF出力時に `第000000000000号` に整形。
- メーカー／車種／色／続柄をプルダウン化（各「その他」で自由記述）。
- **特徴は必須のまま**（古物営業法の法定記載事項のため外せない）。代わりに メーカー／車種／色／フレーム番号／防犯登録番号 から**自動生成**して手入力ゼロで通るようにした。手で追記した場合は自動上書きせず、「自動入力し直す」ボタンで再生成。
- 譲受人の表記を `RAINBOW（めぐり自転車）` に。

**判断が必要だった点**
- 出力ファイル名を取引番号から**お客さま向けの名前**（`8月6日 ○○様 買取.pdf`）に変更した。署名直後にそのままLINEで送るため。**帳簿との照合は書面本文に印字した取引番号で行う。**
  → フェーズ2でDrive保存を作る場合は、要件定義2章の検索性要件を満たすため **Drive側のファイル名には取引番号を先頭に付けること。**
- 同じ月日・同じ氏名が別の年に出るとファイル名が重複する（手元のファイルは送信用の一時コピーという整理）。

### 受け入れ基準の自己チェック（第8章 該当4項目）
- [x] 法定5項目未入力時に署名確定・PDF生成ができない（強制クリックでもPDFは出ない）
- [x] 運転免許証以外の確認区分で番号入力欄が表示されない（PDF本文にも出ない）
- [x] 譲渡証明書と保護者同意書が別PDFとしてA4・1枚ずつ生成される（MediaBox 595.28×841.89 / 1ページを実ファイルで確認）
- [x] 署名確定後にフォームがロックされ確定時刻が記録される（33入力欄が readonly+disabled、署名パッド追記不可）

### 既知の注意点
- 検証用にHTTP（`http://<PCのLAN IP>:8765/kaitori/`）で開くと、ChromeがPDF/画像のダウンロードを「安全にダウンロードできません」と警告する。**これは非HTTPS起点のダウンロードに対するChromeの仕様で、本番の `https://meguri-cycle.com/kaitori/` では出ない。**
- 端末の共有メニューからLINEに送ると、タブレットにログインしている**個人アカウント**から送信される。めぐり自転車として送るには **LINE公式アカウントアプリ**でログインし、1:1チャットからPDFまたはPNGを送ること。
