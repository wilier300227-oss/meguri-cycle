## このプロジェクトは何か
屋号 RAINBOW（めぐり自転車 / 個人事業主）の**出張買取現場向けタブレット記入システム**。
古物営業法の帳簿要件と電子帳簿保存法（電子取引データ）の保存要件を「仕組み」で満たすことが目的。
古物商許可番号：第511090015059号（石川県公安委員会）。譲受人：高多優典（連絡先はPDF非表示）。

- 公開想定URL：`meguri-cycle.com/kaitori/`（既存サイト `wilier300227-oss/meguri-cycle` のサブディレクトリ）
- 対象端末：Redmi Pad SE（Android / Chrome）＋ ディスク型タッチペン
- プリンター：EPSON EW-052A（Wi-Fi Direct 対応 / Bluetooth 非対応）

## 現在の到達点：フェーズ①「完了・実機確認待ち」

**スコープ**：通信・GAS・PWA なしで、端末単体で 入力→署名→確定ロック→PDF生成 まで動く。

### 作成ファイル（すべて `kaitori/` 配下・新規）
- `index.html` — 入力フォーム＋署名UI＋（画面外）A4印刷テンプレート2種
- `app.js` — 採番 / 年齢自動算出 / 本人確認欄の出し分け / 検証 / 確定ロック / PDF生成
- `style.css` — 画面UI＋A4テンプレートのスタイル
- `HANDOFF.md` — 本ファイル

### 実装済みの要点
- 法定5項目（取引年月日・品目/数量・特徴・相手方[氏名/住所/職業/生年月日=年齢]・本人確認方法）を必須化。未充足だと**確定ボタン不活性＋不足項目を一覧表示**。
- 生年月日→**年齢自動算出**。18歳未満で**保護者欄＋保護者署名を自動表示**。
- 本人確認区分プルダウン。**運転免許証選択時のみ**「公安委員会名・番号」欄を表示、他区分は非表示＋値クリア（PDF・後の台帳にも出さない）。
- 取引番号 自動採番 `RB-YYYYMMDD-NNN`（localStorage で日付別連番。確定時に確定）。
- 古物商許可番号を固定表示（編集不可）。
- `signature_pad` で譲渡人（＋未成年時は保護者）の手書き署名。HiDPI対応リサイズ。
- 「確定」で確定時刻（ISO8601）記録＋フォーム全体を readonly/disabled ロック、署名パッド無効化。
- PDFは **jsPDF標準フォントが日本語非対応のため、A4 HTMLテンプレートを `html2canvas` で画像化→jsPDF に配置**する方式。日本語・署名画像をそのまま埋め込み。
  - `{取引番号}_譲渡証明書.pdf`（譲渡証明書 兼 代金受領書・委任状 / A4・1枚）
  - `{取引番号}_保護者同意書.pdf`（**別ファイル** / A4・1枚 / 未成年時のみ）
- CDN読込（signature_pad 4.1.7 / jsPDF 2.5.1 / html2canvas 1.4.1）。※オフライン化はフェーズ③。

- [x] 譲渡証明書と保護者同意書が別PDFとしてA4・1枚ずつ生成される

### 別PCでまず行うこと（実機/ブラウザ確認）
`kaitori/index.html` を Chrome で開き：
1. 必須未入力で確定ボタンが押せない／不足項目が赤表示
2. 確認区分を切替、免許証のときだけ番号欄が出る
3. 生年月日を18歳未満にすると保護者欄が自動表示
4. 署名→確定でロック、2つのPDFがA4 1枚ずつ出力
→ OKならフェーズ②へ。NGなら該当箇所を修正。

### フェーズ②：GAS台帳・Drive連携
- GAS Web App（`doPost`）でフロント送信データを受け、スプレッドシート台帳に1行追記（カラムは要件定義3.5準拠）。GASコードは既存流儀に合わせ `line-bot/` 配下に置く想定。
- **免許証以外は確認番号カラムを空**にする。生成PDFを Drive 保存（ファイル名＝取引番号）、台帳にリンク記録。
- 検索性：取引年月日・買取金額・相手方氏名を独立カラムで保持。訂正は「新規訂正」＋訂正ログ。追記失敗時はローカルキュー再送。URL/トークンは PropertiesService／非コミット設定で管理。

- Wi-Fi Direct 経由で EW-052A へ印刷する導線（端末標準印刷 or EPSON Smart Panel 連携）。端末単独に残さない設計を最終確認。
