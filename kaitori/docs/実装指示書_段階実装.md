## フェーズ① ローカル完結の署名＋PDF生成

**スコープ**: 通信・GAS・PWAなしで、端末単体で入力〜署名〜PDF生成まで動く状態。

**実装内容**
- 単一構成（HTML/JS/CSS）で 第3.1 の入力フォームを作る。
  - 法定5項目（取引年月日 / 古物の品目・数量 / 古物の特徴 / 相手方の住所・氏名・職業・年齢 / 本人確認方法）を**必須化**。未入力なら署名確定・PDF生成を不可にする。
  - 生年月日から**年齢を自動算出**。18歳未満なら保護者欄（氏名・続柄・連絡先・同意署名）を自動表示。
  - 本人確認区分プルダウン（運転免許証 / マイナンバーカード / 健康保険証＋補完書類 / その他）。**運転免許証を選んだ時だけ**「公安委員会名・番号」欄を表示。他区分では番号欄を出さない。
  - 取引番号を自動採番（例 `RB-YYYYMMDD-001`）。
  - 古物商許可番号 第511090015059号を固定表示（編集不可）。
- `signature_pad` で手書き署名を取得（譲渡人、未成年時は保護者も）。
- 「確定」操作で署名確定時刻（ISO8601）を記録し、フォーム全体を編集ロック。
- `jsPDF` で以下を**別ファイル**として生成。
  - 譲渡証明書 兼 代金受領書・委任状（A4・1枚）
  - 保護者同意書（A4・1枚、未成年時のみ）
  - 譲受人（高多優典）の連絡先欄は非表示。署名画像・取引番号・確定時刻・古物商許可番号をPDFに埋め込む。

**このフェーズでやらないこと**: GAS台帳連携、Drive保存、PWA/オフライン、Wi-Fi Direct印刷の作り込み（標準印刷でPDFが出れば可）。

**自己チェック（第8章 該当項目）**
- [ ] 法定5項目未入力時に署名確定・PDF生成ができない
- [ ] 運転免許証以外の確認区分で番号入力欄が表示されない
- [ ] 譲渡証明書と保護者同意書が別PDFとしてA4・1枚ずつ生成される
- [ ] 署名確定後にフォームがロックされ確定時刻が記録される

→ 完了報告後、実機確認OKの指示を待ってフェーズ②へ。

## フェーズ② GAS台帳・Drive連携

**スコープ**: フェーズ①の生成結果を、検索可能な台帳とクラウド保存に接続する。

**実装内容**
- Google Apps Script Web App（`doPost`）を作成し、フロントから送信された取引データを受け取る。
  - スプレッドシート台帳に1行追記。カラムは要件定義 3.5 のカラム例に準拠（取引番号 / 取引年月日 / 相手方氏名 / 住所 / 職業 / 年齢 / 本人確認区分 / 確認番号（免許証時のみ）/ メーカー / 車種 / フレーム番号 / 色 / 防犯登録番号 / 数量 / 特徴 / 買取金額 / 支払方法 / 未成年フラグ / 保護者氏名 / 署名確定時刻 / PDFリンク / 訂正ログ）。
  - **番号を書き写せない本人確認区分の値は台帳にも保存しない**（免許証以外は確認番号カラムを空にする）。
  - 生成PDFを Drive に保存（ファイル名＝取引番号）。台帳にDriveリンクを記録。
- 検索性: 取引年月日・買取金額・相手方氏名を独立カラムで保持し検索可能にする。
- 真実性: 確定後の修正は「新規訂正」扱いとし、台帳の訂正ログに履歴を残す。
- 台帳追記失敗時はローカルにキューして再送する。
- GAS Web AppのURL・トークンは PropertiesService／設定ファイルで管理し、コミットしない。

**自己チェック（第8章 該当項目）**
- [ ] 台帳が取引日・金額・相手方氏名で検索できる
- [ ] 免許証以外の確認区分で確認番号が台帳に保存されない
- [ ] PDFがDriveに取引番号名で保存され、台帳からリンクで開ける

→ 完了報告後、動作確認OKの指示を待ってフェーズ③へ。

## フェーズ③ PWAオフライン対応・印刷仕上げ

**スコープ**: 通信のない現場でも完結し、復帰時に同期。印刷導線を仕上げる。

**実装内容**
- PWA化（`manifest.json` ＋ Service Worker）。通信がなくても入力・署名・PDF生成が完結する。
- オフライン中の台帳追記・Drive保存はローカルキューに退避し、**通信復帰時に自動同期**。
- Wi-Fi Direct 経由で EW-052A へ印刷する導線を整える（端末標準印刷 or EPSON Smart Panel 連携）。
- 保存方針の最終確認: 端末単独に残さない設計になっていること。

**自己チェック（第8章 該当項目）**
- [ ] オフラインで入力〜PDF生成が完結し、復帰時に同期される
- [ ] Wi-Fi Direct で EW-052A に印刷できる

→ 完了報告後、全体の受け入れ基準（第8章）を通しで自己チェックし報告。
