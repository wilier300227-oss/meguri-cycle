# タブレット記入システム 要件定義書

**事業者**: 屋号RAINBOW（個人事業主）／めぐり自転車
**古物商許可番号**: 第511090015059号（石川県公安委員会）
**作成目的**: 出張買取現場でタブレット上に取引書類を記入・署名し、古物営業法の帳簿要件と電子帳簿保存法の電子取引データ保存要件を「仕組みとして」満たす。

---

## 0. 前提・既存資産（流用対象）

- ホスティング: GitHub Pages（オーナー `wilier300227-oss`）
- バックエンド: Google Apps Script（既存のLINEボット運用と同基盤）。トークンは PropertiesService 管理、`.env` はコミットしない
- 端末: Redmi Pad SE（11インチ / Android）＋ 市販ディスク型タッチペン
- プリンター: EPSON EW-052A（Wi-Fi Direct 対応 / Bluetooth 非対応）
- 保存先クラウド: Google Drive
- ブランド運用: 顧客向けは「めぐり自転車」、証明書・受領書の事業者名は「RAINBOW」

---

## 1. スコープ

出張買取1件ごとに、以下をタブレット完結で実行する。

1. 取引情報・相手方情報・自転車情報・金額の入力
2. 本人確認区分の記録（法令準拠）
3. 手書き署名の取得と確定時刻の記録
4. 譲渡証明書PDF・（未成年時）保護者同意書PDFの**別ファイル**生成
5. Wi-Fi Direct でその場印刷
6. 検索可能な台帳（スプレッドシート）への自動追記と Drive へのPDF保存

---

## 2. 法令要件と充足方法（最重要）

| 法令要件 | 本システムでの充足方法 | 実装上の必須制約 |
|---|---|---|
| 古物営業法 法定5項目の記録 | ①取引年月日 ②古物の品目・数量 ③古物の特徴 ④相手方の住所・氏名・職業・年齢 ⑤本人確認方法 をフォーム必須化 | 5項目未入力時は署名確定・PDF生成を不可にする |
| 古物台帳 3年保存・即時書面表示 | 全PDFをDrive保存＋台帳から即出力。保存年数は税務側に合わせ**7年で統一** | ファイル名は取引番号で統一し即検索可能に |
| 本人確認方法の記録 | 確認区分をプルダウン化 | **運転免許証を選んだ時のみ**「公安委員会名・番号」入力欄を表示 |
| マイナンバーカード/保険証の番号記録禁止 | 該当区分では**番号入力欄を一切表示しない** | 番号・写しをDBやPDFに保存しないこと |
| 電帳法 真実性（改ざん防止） | (a) 署名確定時刻の自動記録 (b) 台帳の訂正削除ログ (c) 事務処理規程の備付け の3点併用 | 署名確定後はフォームをロック |
| 電帳法 可視性（検索要件） | 取引年月日・取引金額・取引先氏名で検索可能な台帳 | 3項目を台帳の独立カラムに保持 |
| 電帳法 バックアップ | Drive自動保存＋定期バックアップ | 端末のみに残さない |

> 注: 普通自転車は少額例外品目（バイク・原付・ゲームソフト・CD/DVD・書籍）に含まれないため1万円未満は帳簿記載を省略可だが、本システムは**全件記録**の方針とする。

## 3. 機能要件

### 3.1 入力フォーム

**取引情報**
- 取引番号（自動採番。例: `RB-YYYYMMDD-001`）
- 取引年月日（既定は当日、変更可）
- 取引区分（買取 / 引取 等）

**相手方情報（法定）**
- 氏名
- 住所
- 職業
- 生年月日 → **年齢を自動算出**（未成年判定にも使用）

**本人確認**
- 確認区分プルダウン: 運転免許証 / マイナンバーカード / 健康保険証＋補完書類 / その他
- 運転免許証選択時のみ表示: 公安委員会名・番号（例「石川県公安委員会 第○○○○号」）
- 上記以外の区分では番号入力欄を出さない

**対象自転車**
- メーカー / 車種 / フレーム番号 / 色 / 防犯登録番号 / 数量 / 特徴（自由記述）

**金額**
- 買取金額
- 支払方法（現金 / 振込）

**誓約事項**
- チェックボックス（盗品でないこと等の確認）

**固定表示**
- 古物商許可番号 第511090015059号（編集不可）

**未成年時（年齢 < 18 で自動表示）**
- 保護者氏名 / 続柄 / 連絡先 / 保護者同意署名欄

### 3.2 署名・確定
- `signature_pad` 等で手書き署名を取得（譲渡人。未成年時は保護者も）
- 「確定」操作で署名確定時刻（ISO8601）を記録し、フォーム全体を編集ロック
- 確定後の修正は「新規訂正」扱いとし、台帳に訂正ログを残す

### 3.3 PDF生成
- 譲渡証明書 兼 代金受領書・委任状: A4・1枚に収容
- 保護者同意書: **別PDF**として A4・1枚（未成年時のみ）
- 2書類が1ファイルで途中改ページする従来問題を解消すること
- 譲受人（高多優典）の連絡先欄は非表示（既存仕様踏襲）
- 署名画像・古物商許可番号・取引番号・確定時刻をPDFに埋め込む

### 3.4 印刷
- Wi-Fi Direct 経由で EW-052A へ出力（EPSON Smart Panel 連携 or 端末標準印刷）

### 3.5 台帳・保存
- Apps Script Web App 経由でスプレッドシート台帳に1行追記
  - カラム例: 取引番号 / 取引年月日 / 相手方氏名 / 住所 / 職業 / 年齢 / 本人確認区分 / 確認番号（免許証時のみ） / メーカー / 車種 / フレーム番号 / 色 / 防犯登録番号 / 数量 / 特徴 / 買取金額 / 支払方法 / 未成年フラグ / 保護者氏名 / 署名確定時刻 / PDFリンク / 訂正ログ
- 生成PDFを Drive に保存（ファイル名は取引番号）。台帳にPDFのDriveリンクを記録
- **番号を書き写せない本人確認区分の値は台帳にも保存しないこと**

## 4. 非機能要件

- **オフライン動作**: PWA化し、通信がない現場でも入力・署名・PDF生成が可能。通信復帰時に台帳・Driveへ自動同期
- **単一端末完結**: Redmi Pad SE の Chrome でアプリ追加インストール不要
- **セキュリティ**: GASトークンは PropertiesService。`.env` は非コミット。本人確認書類の番号・写しは非保持（免許証の公安委員会名＋番号のみ許容）
- **保存**: 全書類7年保存。端末単独保存にしない
- **可用性**: 台帳追記失敗時はローカルにキューし再送

## 7. スコープ外・要確認事項

- **防犯登録手続きでの電子データ受理可否**: 管轄防犯協会・警察署の運用に依存。電子のみで完結できるか要事前確認（メール・窓口での確認手段を優先）
- **事務処理規程**: 別ファイル（事務処理規程ひな形）を運用開始前に整備・備付け
- **保護者本人確認の運用**: 身分証提示との併用手順はマニュアルで別途定義
- 個別の税務判断は顧問税理士・所轄税務署への確認を推奨

## 8. 受け入れ基準（抜粋）

- [ ] 法定5項目未入力時に署名確定・PDF生成ができない
- [ ] 運転免許証以外の確認区分で番号入力欄が表示されない
- [ ] 譲渡証明書と保護者同意書が別PDFとしてA4・1枚ずつ生成される
- [ ] 署名確定後にフォームがロックされ確定時刻が記録される
- [ ] 台帳が取引日・金額・相手方氏名で検索できる
- [ ] オフラインで入力〜PDF生成が完結し、復帰時に同期される
- [ ] Wi-Fi Direct で EW-052A に印刷できる
