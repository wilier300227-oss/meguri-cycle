# LINE自動応答システム セットアップ手順

対象：`line-bot/code.gs`（LINE Messaging API の GAS Webアプリ）＋リッチメニュー。
仕様は `line-bot/handoff_line_system.md` を参照。作業は **1 → 3 → 2 の順**が安全。

---

## タスク1：GAS再デプロイ＋設定

### 1-1. LINEボットのGASプロジェクトを開く
[script.google.com](https://script.google.com) → LINEボットのプロジェクト（`code.gs` があるもの。台帳の `kaitori-ledger.gs` とは**別プロジェクト**）。

### 1-2. コードを最新化
1. 先に、今GASに入っている **`CHANNEL_ACCESS_TOKEN` と `OWNER_LINE_USER_ID` の実値をメモ**（貼り付けで消えるため）。
2. リポジトリの `line-bot/code.gs` を全部コピー → GASエディタの `code.gs` に**全置換で貼り付け** → 保存。
3. 上部の定数を**実値に戻す**：
   - `CHANNEL_ACCESS_TOKEN`（チャネルアクセストークン）
   - `OWNER_LINE_USER_ID`（下の 1-3 で取得）
   - `GOOGLE_REVIEW_URL`（口コミリンク。未定なら空でOK）
   - `REVIEW_AUTO_ENABLED` は `false` のまま
   - ※ `inquiry-sync.gs` 等の他ファイルは既存のまま（今回変更なし）

### 1-3. OWNER_LINE_USER_ID を取得
個人LINEで「めぐり自転車」を友だち追加 → トークで **`MYID`** と送信 → ボットが `あなたのuserId:U…` を返信 → その `U…` を `OWNER_LINE_USER_ID` に貼る → 保存。
（返信が来ないときは先に 1-6 のデプロイ後に再度 `MYID`）

### 1-4. 中央シート（INQUIRY_SHEET_ID）を用意
関数リストで **`getInquirySheet_`** を選び ▶実行（初回は権限承認）。→ 問い合わせ用スプレッドシートが自動作成され、`INQUIRY_SHEET_ID` がスクリプトプロパティに登録される。
（`log` / `users` / `fee_master` タブはこのスプレッドシート内に作られる）

### 1-5. 出張費マスタを作成→料金確定
1. 関数リストで **`initFeeMaster_`** を ▶実行 → `fee_master` タブが暫定額で作成される。
2. スプレッドシートの `fee_master` の **「出張費」列を実測（かほく市役所起点の走行距離）で確定**。**単一額のみ**（レンジ禁止）。エリア外は「対応可否」を `要相談` に。備考「要確認」を消す。
3. 反映は最大5分（キャッシュ）。

### 1-6. 再デプロイ（URLは変えない）
右上 **デプロイ → デプロイを管理 → 対象の鉛筆✎ → バージョン「新バージョン」→ デプロイ**。
※「新規デプロイ」ではなく**既存を編集**すれば **URLは不変**で、LINEのWebhook設定はそのままでOK。

### 1-7.（任意）リッチメニュー自動切替を使う場合
リッチメニューをAPIで作成/登録した場合、スクリプトプロパティに
`RICHMENU_A_ID` / `RICHMENU_B_ID` を設定すると、申込でBへ・停止でAへ自動切替する。
未設定なら何もしない（メニュー1つ運用でも問題なし）。

## タスク3：管理画面のキーワード応答・挨拶文を整理

[LINE Official Account Manager](https://manager.line.biz) → 対象アカウント →

### 3-1. 応答設定（設定 → 応答設定）
- **応答モード：Bot（チャット）**
- **Webhook：オン**（GASのURLが登録されていること）
- **応答メッセージ：オフ** ← ★地名キーワード誤爆・二重送信の主因。必ずオフ
- **AI応答メッセージ：オフ**

### 3-2. あいさつメッセージ（ホーム → あいさつメッセージ）
- 文面から **「48時間以内」「出張費の金額」を削除**（GAS側に集約済み）。
- 残す（特商法 訪問購入の前提として重要）：
  - お伺いするのは金額が決まったあとです
  - 査定のためだけの訪問は承っておりません
  - 先に金額を確定させています（玄関先で交渉しません）
- 金額を書きたい場合は**料金ページのリンク**に置換（数字は書かない）。

## タスク2：リッチメニュー登録

[LINE Official Account Manager](https://manager.line.biz) → **ホーム → リッチメニュー → 作成**

### 2-1. メニューA（通常時・既定表示）
1. タイトル `メニューA`、テンプレート **大 → 6分割（3×2）**。
2. 背景画像：**`line-richmenu-final.png`**（リポジトリ直下）をアップロード。
3. 各エリア → アクション「テキスト」→ 下の text を入力（左上→右、次段）：

| 位置 | ボタン | テキスト |
|---|---|---|
| 左上 | 買取を申し込む | `買取査定を申し込みます` |
| 中上 | 処分・引取 | `出張引取を申し込みます` |
| 右上 | 対応エリア・出張費 | `対応エリア・出張費` |
| 左下 | 査定をお願いします | `査定をお願いします` |
| 中下 | よくある質問 | `よくある質問` |
| 右下 | 担当者に相談 | `担当者に相談` |

4. チャットバー：`メニュー`。**保存 → 表示（デフォルト）に設定**。

### 2-2. メニューB（査定中〜訪問確定後・任意）
画像 **`line-richmenu-b-final.png`**、各 text：
`写真を追加する` / `台数を追加する` / `進捗を確認` / `日程を変更したい` / `担当者に相談` / `キャンセル・やめる`
⚠ **Bはデフォルト表示にしない**（Aを既定）。

### 2-3. A↔B の切替（API・任意）
- 各メニューの `richMenuId` を控え、`RICHMENU_A_ID`/`RICHMENU_B_ID` をスクリプトプロパティに設定すると、GASが申込でB・停止でAへ自動で紐付け替え。
- 手動で切り替える場合の API：
  - 表示：`POST https://api.line.me/v2/bot/user/{userId}/richmenu/{richMenuId}`
  - 解除：`DELETE https://api.line.me/v2/bot/user/{userId}/richmenu`
  - ヘッダ：`Authorization: Bearer <チャネルアクセストークン>`
- 参照JSON：`line-bot/richmenu_A.json` / `richmenu_B.json`（API登録にそのまま使える）。

## 反映後の動作チェック
- `MYID` 返信が来る（トークン/デプロイOK）
- 「買取希望」→「金沢市」で**出張費を出さない**（買取は無料のみ）
- 住所だけ送っても料金が出ない／写真連投で自動応答が割り込まない
- 分類できない質問で**自分のLINEに通知**（`OWNER_LINE_USER_ID` 設定後）
- スプレッドシート `log` に記録、`fee_master` の額が反映
