# めぐり自転車 LINEボット セットアップ手順

Google Apps Script（GAS）で動く無料の自動応答ボット。`code.gs` を使う。

## できること

- リッチメニュー「写真を送る」タップ → 撮影ガイド（まずは3枚＋任意で詳細）＋ボタン（📷写真を選ぶ／📸カメラで撮る／⚡電動アシスト）を自動返信
- 「電動」と送信 → 電動アシスト用の追加ガイド（バッテリー・充電器・鍵）を返信
- 写真を受信 → お礼メッセージを自動返信（10分に1回まで）
- それ以外のメッセージには反応しない（手動チャット対応の邪魔をしない）
- Googleロコミ依頼：現在は**手動運用**（送る相手・タイミングがケースバイケースのため）。オーナーがLINE公式アカウントアプリの1:1チャットから手動で送る。文面は `code.gs` の `REVIEW_MESSAGE_TEXT`（`REVIEW_AUTO_ENABLED=true` で従来の自動送信に戻せる）
- 写真送信・申し込み・初回メッセージを中央スプレッドシートに記録し、オーナー個人のLINEに通知（見逃し防止）

## 費用

0円。応答メッセージは月200通の無料枠にカウントされない。GASも無料。

## セットアップ手順

### 1. Messaging APIを有効化

1. [LINE Official Account Manager](https://manager.line.biz/) にログイン
2. 設定 → Messaging API → 「Messaging APIを利用する」
3. プロバイダー名は「めぐり自転車」などで新規作成

### 2. チャネルアクセストークンを発行

1. [LINE Developers](https://developers.line.biz/console/) にLINEアカウントでログイン
2. 作成されたチャネルを開く → 「Messaging API設定」タブ
3. 一番下の「チャネルアクセストークン（長期）」で「発行」を押してコピー

### 3. GASプロジェクトを作成

1. [script.google.com](https://script.google.com/) → 「新しいプロジェクト」
2. `code.gs` の中身を全部貼り付け
3. 1行目付近の `CHANNEL_ACCESS_TOKEN = 'ここに...'` にコピーしたトークンを貼る
4. 右上「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
5. 「デプロイ」→ 表示された **ウェブアプリのURL** をコピー

### 4. WebhookをLINEに登録

1. LINE Developers → チャネル → Messaging API設定タブ
2. 「Webhook URL」にGASのURLを貼り付けて「更新」→「検証」
3. 「Webhookの利用」をONにする

### 5. 応答設定を調整（重要）

LINE Official Account Manager → 設定 → 応答設定：

- チャット：**ON**（手動対応を残す）
- Webhook：**ON**
- 応答メッセージ：**OFF**（ボットと二重返信になるため。キーワード応答を設定していた場合は削除）

### 6. 動作テスト

自分のスマホで友だち追加したアカウントに対して：

1. リッチメニュー「写真を送る」をタップ → ガイドとボタン3つが返ってくる
2. 「⚡電動アシストの方はこちら」ボタン → 電動用ガイドが返ってくる
3. 「📷 写真を選ぶ」ボタン → スマホの写真選択が開く
4. 写真を送る → お礼メッセージが返ってくる

## レビュー依頼（Googleロコミ）— 現在は手動運用

送る相手・タイミングがケースバイケースのため、**自動送信はオフ**（`code.gs` の `REVIEW_AUTO_ENABLED = false`）。
オーナーが判断して、LINE公式アカウントアプリの1:1チャットから手動で送る運用です。

### 手動での送り方

1. `GOOGLE_REVIEW_URL` にGoogleビジネスプロフィールの口コミ投稿リンクを設定しておく（`code.gs`）
2. 送る文面は `code.gs` の `REVIEW_MESSAGE_TEXT` を使う。**LINE公式アカウントアプリの「定型文（テンプレート）」に一度登録**しておくと、チャットからワンタップで挿入できて便利
3. 取引が済んで満足いただけたお客さまのトーク画面を開き、その文面を送信

### 手動運用への切り替え時にやること（GAS側）

1. GASエディタで最新の `code.gs` に差し替えて保存 → 「デプロイを管理」→ 新バージョンでデプロイ
2. 以前に自動送信のトリガーを作成済みなら、関数選択プルダウンで **`uninstallReviewTrigger`** を選び ▶実行（日次トリガーを削除。残っていても `REVIEW_AUTO_ENABLED=false` の間は何も送りませんが、無駄な起動をなくすため削除推奨）

### 将来また自動送信に戻す場合

1. `code.gs` の `REVIEW_AUTO_ENABLED` を `true` にして保存・デプロイ
2. `installReviewTrigger` を▶実行（毎日10時に `sendReviewRequests` を実行するトリガーを登録）
3. 動作：顧客が写真を送る→キュー記録→`REVIEW_REQUEST_DELAY_DAYS`（既定10日）経過後に自動プッシュ。会話中に「キャンセル/やめ/見送り/他で決め/結構です/不成立/なしで」を含むと自動で取消（`skipped`）

## 問い合わせの一元管理・オーナー通知（追加機能）

Gmail（`inquiry-sync.gs`）・Googleフォーム（`form-sync.gs`）に加えて、LINEでの主要なアクション（写真送信・買取査定/出張引取の申し込み・初回メッセージ）も同じ中央スプレッドシートに記録し、記録されるたびにオーナー個人のLINEにプッシュ通知します。公式アカウントの通知だけだと見逃しの可能性があるための対策です。

クイックリプライのボタン操作（「買取希望」「対応エリア」など）は記録・通知の対象外です。同じ会話が何行にも分裂して逆に見づらくなるのを防ぐためで、初回の接点（写真送信・申し込み・初回メッセージ）だけを拾う設計にしています。

### 有効化の手順

1. GASエディタで `code.gs`・`inquiry-sync.gs`・`form-sync.gs` を最新版に差し替えて保存
2. 個人のLINEで「めぐり自転車」を友だち追加していない場合は追加する
3. 個人のLINEから「めぐり自転車」に **`MYID`** と送信 → 自分の`userId`が返信されてくる
4. その`userId`をコピーして、`code.gs`の `OWNER_LINE_USER_ID` に貼り付けて保存
5. 「デプロイ」→「デプロイを管理」→ 鉛筆アイコン → 新バージョンでデプロイ

### 動作イメージ

- お客様がLINEで写真送信・申し込み・初回メッセージのいずれかを行う
- 中央スプレッドシート（`めぐり自転車_問い合わせ一元管理`）に「経路：LINE」として1行追加
- 同時に、オーナー個人のLINEに「📩 新しい問い合わせ（LINE）＋送信者名＋内容の抜粋＋シートへのリンク」がプッシュ通知される
- Gmail・フォームからの問い合わせも、同じ仕組みで記録時に自動的にオーナーへ通知される（`appendInquiryRow_`が経路に関わらず共通で呼ばれるため）

## 文言を変えたいとき

`code.gs` の `replyPhotoGuide` / `replyEbikeGuide` / `thankForPhoto` 内のテキストを編集 →
保存 → 「デプロイ」→「デプロイを管理」→ 鉛筆アイコン → バージョン「新バージョン」→「デプロイ」。
（新バージョンでデプロイし直さないと反映されないので注意）

## 注意

- チャネルアクセストークンは秘密情報。GAS内にのみ貼り、Gitにはコミットしない
- カメラ／カメラロールのボタンはスマホ版LINEのみ表示（PC版では出ない）
