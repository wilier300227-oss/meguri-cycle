# docs/research/

## 目的

このディレクトリは **外部リサーチ成果物の置き場** です。

深い調査（市場調査・法令確認・技術選定の比較検討など）は Claude Code の中では行わず、
claude.ai の Research 機能、または Perplexity の Deep Research で実施します。
その成果物を Markdown にしてここに置き、Claude Code が作業時に参照します。

Claude Code 自身は大量の WebSearch を回しません（セッションあたりの検索上限を温存するため）。
運用ルールの詳細はルートの `CLAUDE.md` の「調査資料の扱い」を参照してください。

## ファイル命名規則

```
YYYY-MM-DD-テーマ名.md
```

- `YYYY-MM-DD` は **調査を実施した日** です（ファイルを置いた日ではありません）
- `テーマ名` は内容が一目で分かる短い名前にします（例: `2026-09-09-mercari-api-rate-limit.md`）
- 新しいファイルは `_template.md` をコピーして作成してください

## 更新時のルール

- 同じテーマを再調査したときは **ファイルを新規作成** します（新しい日付で）
- 古いファイルは削除せず残します（過去時点での知見・比較のため）
- 古いファイルの frontmatter の `status` を `stale` に変えておくと、参照時に判別しやすくなります

## ファイル構成

| ファイル | 役割 |
|---|---|
| `README.md` | このファイル。運用ルール |
| `_template.md` | 新規ファイル作成用の雛形 |
| `YYYY-MM-DD-*.md` | 調査成果物 |
