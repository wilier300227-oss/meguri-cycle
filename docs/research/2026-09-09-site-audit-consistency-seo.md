### タスク2：事実との矛盾・要注意点（重要度順）

**［高：法的リスク・信頼毀損］防犯登録抹消の「その場で代行」断言 vs 協会加入申請中**
- 該当（トップ）：「防犯登録の抹消手続きもその場で代行します」／「抹消手続きは当方で代行します。書類がなくても対応可能なケースが多いです」／選ばれる理由「防犯登録の抹消も代行」／meta descriptionにも「防犯登録の抹消も代行します」。
- 矛盾：防犯登録協会への加入が**申請手続き中（未完了）**。加入完了前に抹消代行を無条件で断言すると、実行不能時に不当表示・信頼毀損リスク。
- 修正案（修正前→修正後）：「防犯登録の抹消手続きもその場で代行します」→「防犯登録の抹消手続きもサポートします（お客様に代わって手続きを進めます。詳しくはご相談ください）」。**協会加入が完了した時点で「代行」表現に戻す。**

**［中：信頼・SEO］title/OGPが石川限定で富山を取りこぼし**
- 該当：title「めぐり自転車｜石川の自転車出張買取・引取（かほく・金沢）」／og:title「めぐり自転車｜石川の自転車出張買取・引取」。一方でフッターは「対応エリア 全25市町」に富山県7市（氷見・高岡・小矢部・射水・砺波・富山・南砺）を明記。
- 矛盾：実エリアは石川＋富山だが、最重要のtitle/OGPが石川のみ。富山（高岡が好調）の集客を取りこぼす。
- 修正案：title→「めぐり自転車｜石川・富山の自転車出張買取・引取（かほく・金沢・高岡）」。og:titleも富山を含める。

**［軽微：整合・SEO］出張費距離表に富山県の市町が無い**

## ローカル検証結果（2026-09-11、Claude Code がリポジトリのソースで確認）

原報告が「下層ページ未取得のため未検証」とした項目を、リポジトリ内の HTML ソース（`_site/` を除く）で確認した結果。WebSearch は使っていない。

### 原報告の指摘が正しいと確認できたもの
- **title / og:title は石川限定**：`index.html` 11行・14行。meta description と og:description も「防犯登録の抹消も代行します」と断言。
- **「その場で代行します」は `index.html` の1箇所**。ただし「防犯登録の抹消手続きは当方で代行します」が市町ページ25ページに、「こちらで代行」等の類似表現が about・hikitori・terms・privacy・column/recall・lp に散在（合計33ファイル）。修正するなら全ページ一括で表現を統一する必要がある。
- **「電話でのお問い合わせは現在受け付けておりません」**：`index.html` 507行の1箇所のみ。
- **出張費表に富山の市町が無い**：`index.html` の距離帯リストは石川のみで、50km超の行が「上記以外の市町」。一方 `takaoka.html` 121行は「かほく市役所から高岡駅周辺までおよそ39km」と記載しており、距離ルール上は〜40km帯（¥2,500）に入る。トップの表と高岡ページの記述が噛み合っていない。

### 原報告の懸念が解消済み・問題なしと確認できたもの
- **JSON-LD に telephone は無い**。address は `addressLocality: かほく市` のみで、`streetAddress`・`postalCode` は全ページ無し（サービスエリア型として適切）。`priceRange` は "¥0～¥3,000"。

- **禁止用語**：「高価買取」「転売」「出張修理」「TEL」は全ページ検出なし。電話番号のパターンも検出なし。「お電話」は `about.html` 144行の「お電話の窓口もなく」という否定文のみ。
