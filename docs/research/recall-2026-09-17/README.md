# リコール型番一覧の作り方と出典

- `/column/recall/` の表は `_data/recalls.json` から生成する。JSON はこのフォルダの `gen.py` で作った。
- `gen.py` は、公式ページを取得してテキスト化した `*.txt`（作業時は scratchpad に保存。リポジトリには置いていない）から、品番・号機番号の範囲・製造ロットを正規表現で抜き出す。型番を手で打たないため。
- 抜き出した 139 件の型番・号機範囲と 130 件の製造ロットは、すべて公式本文の文字列と一致することを確認済み（2026-09-17）。
