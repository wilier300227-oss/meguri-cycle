# Google 口コミ依頼（LINE 用）

作成：2026-09-16（SEO 改善要件定義 T1-2）。オーナー承認後に確定。
LINE ボットのプリセットには入れない（ボットは作り直し中）。取引完了後に手動で送る。

## 依頼文（取引完了後、当日中に送る）

```
本日はありがとうございました。
もしよろしければ Google の口コミで感想をいただけると、次に自転車を手放す方の参考になります。率直な内容で大丈夫です。
https://meguri-cycle.com/review/
```

- リンクは /review/ 固定（Google の口コミ投稿画面へ自動で飛ぶ。訪問数を Cloudflare で計測し、週次レポートの定点観測に出る）。
- 特典・割引・抽選は付けない。家族・知人への投稿依頼もしない（景品表示法・Google のポリシー）。
- 催促はしない。送るのは1回だけ。
- 買取に至らなかった方（引取のみ、お断りされた方）にも同じ文面でよい。無理に送らなくてよい。

## 口コミへの返信ルール

- 24時間以内に返信する（遅れても必ず返す）。
- 1〜3文。最初にお礼、次に取引内容に触れる一言、最後に一言添える。
- 地域名とサービス名を自然に入れる（例：「金沢市までの出張買取」「電動アシスト自転車のバッテリー診断」）。詰め込まない。
- 禁止語は使わない：「高価買取」「転売」「国家資格」。「転売」の意味が必要なら「リユース品価格調査」。
- 電話番号・住所・お客さまの個人情報（氏名、町名より細かい場所、車体の詳細）は書かない。
- 低評価にも同じ姿勢で。言い訳や反論はせず、事実と改善したことだけを書く。

### 返信例

- 高評価：「ご利用ありがとうございました。金沢市までの出張買取で、バッテリーの状態も含めてご説明できてよかったです。また自転車のことで困ったときはお気軽にどうぞ。」
- 引取のみ：「お引き取りのご依頼ありがとうございました。値段のつかない自転車でも、部品として活かせるものはお引き取りしています。ご相談いただけて助かりました。」
- 低評価：「ご指摘ありがとうございます。○○の点でご不便をおかけしました。△△を見直しました。貴重なご意見として受け止めます。」
